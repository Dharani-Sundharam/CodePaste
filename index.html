Why CTpaste?

Everything a student needs to type code instantly and naturally into any IDE.

Real Keystrokes

Sends input via the system API — indistinguishable from manual typing at the OS level. No macros, no paste.

3 Speed Modes

Slow, Medium, or Fast — with natural random delays that mimic real human typing rhythm so it never looks robotic.

IDE-Aware

How to Use CTpaste

Quick start: download, sign in, run, and type with Alt+V.

Before You Start

  • Windows 10 / 11 (64-bit) or Ubuntu 20.04+ for the desktop app
  • A CTpaste account (create one in under a minute)
  • Your IDE open and ready (VS Code, IntelliJ, Eclipse, etc.)
1

Download the App

Choose your platform from the Download section below and install or open the app.

2

Create Account & Sign In

Go to the Login page, create your account with roll number, then sign in from the app.

3

Start Session

Open CTpaste.exe or CTpaste.AppImage, log in, and click Start so the app is ready.

4

Copy, Focus, Press Alt+V

Copy code with Ctrl+C, place your cursor in the IDE, then press Alt+V. CTpaste types it naturally in real time.

AI

AI Assist Addon

Purchase the AI Addon (₹45/day) from your dashboard. Open the AI Assist card, paste your free Groq API key, click Verify → Save. Then use these hotkeys:

Alt+BStart capturing your question — type freely in your IDE
Alt+GSubmit to Groq AI — answer is typed live into your IDE
Alt+BAsk a follow-up — conversation history is preserved
Alt+NClear history and start a completely fresh conversation

💡 The status bar shows how many turns are in memory, e.g. [2 turn(s) in memory]. Press Alt+N any time to reset.

Tips & Tricks

  • Use Slow speed if your IDE misses characters
  • Do not type while CTpaste is running a paste action
  • For phone sync, log in on Android and tap Login & Sync
  • If typing pauses, click Stop → Start and try Alt+V again

🐧 Linux Installation Guide

CTpaste ships as a self-contained AppImage — no installation, no dependencies (except xdotool).

  1. Download CTpaste.AppImage from the Download section.
  2. Make it executable — right-click → Properties → Permissions → Allow executing as program, or run: chmod +x CTpaste.AppImage
  3. Double-click to launch — no install needed!

Quick walkthrough:

⚠ Requires Ubuntu 20.04+ / GLIBC 2.31+. Install xdotool first: sudo apt install xdotool
