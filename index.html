Why CTpaste?

Everything a student needs to type code instantly and naturally into any IDE.

How to Use CTpaste

Quick start: download, sign in, run, and type with Alt+V.

Before You Start

  • Windows 10 / 11 (64-bit) or Ubuntu 18.04+ / equivalent amd64 Linux for the CLI/desktop app — see Linux Installation Guide below for the standalone binary
  • A CTpaste account (create one in under a minute)
  • Your IDE open and ready (VS Code, IntelliJ, Eclipse, etc.)
1

Download the App

Choose your platform from the Download section below and install or open the app.

2

Create Account & Sign In

Go to the Login page, create your account with roll number, then sign in from the app.

3

Start Session

Windows: open CTpaste.exe, log in, and click Start. Linux: run the CTpaste binary in a terminal (see Linux guide), answer Y when asked to start listening — no separate GUI window.

4

Copy, Focus, Press Alt+V

Copy code with Ctrl+C, place your cursor in the IDE, then press Alt+V. CTpaste types it naturally in real time.

Tips & Tricks

  • Use Slow speed if your IDE misses characters
  • Do not type while CTpaste is running a paste action
  • For phone sync, log in on Android and tap Login & Sync
  • If typing pauses, click Stop → Start and try Alt+V again

🐧 Linux Installation Guide (Ubuntu & Debian-based)

Linux uses a single executable (CLI, no GUI — everything bundled with PyInstaller --onefile). After you run it, you enter your registration number and password, see a short summary, then Y/N to start listening for Alt+V (paste), Alt+B / Alt+G / Alt+N (AI). Windows users keep the graphical .exe.

Standalone binary

  1. Download CTpaste from the Linux row below (one file, no installer).
  2. Open a terminal in the folder where you saved it (e.g. cd ~/Downloads).
  3. Allow execute permission: chmod +x CTpaste (or right‑click → Properties → Permissions → Execute).
  4. Run: ./CTpaste — follow the prompts; press Y + Enter to start hotkeys. Stop with Ctrl+C.
  5. Optional — install into PATH: sudo cp CTpaste /usr/local/bin/ctpaste && sudo chmod +x /usr/local/bin/ctpaste then run ctpaste from anywhere.

Quick walkthrough

⚠ Compatibility: Official Linux builds should be produced on Ubuntu 18.04 (or the repo’s Docker Bionic scripts) so the binary runs on 18.04 → 24.04+ on amd64. A binary built only on Ubuntu 22.04 may fail on 18.04 with a GLIBC error. Global hotkeys need X11 on many setups — choose Ubuntu on Xorg at login if Alt+V fails on Wayland; for AI capture, add your user to the input group for evdev (see project README).
